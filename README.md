# SafetyStart

A React Native (Expo) app I'm building as a **learning project** to get hands-on with React Native and Expo Router.

This isn't a production app — it's a personal sandbox for practicing:

- React Native fundamentals (Views, Flexbox, StyleSheet)
- Component structure & props
- Expo Router (file-based routing)
- Building a real UI from a design instead of just following tutorials

## Status

🚧 Early stage / actively learning — expect rough edges, hardcoded data, and refactors as I go.

## Tech Stack

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/) + [Expo Router](https://docs.expo.dev/router/introduction/)

## Getting Started

```bash
npm install
npx expo start
```
